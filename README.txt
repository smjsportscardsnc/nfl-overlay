SMJ Graphic Swoosh Overlay

Use:
- index.html in OBS Browser Source, 1920x1080
- control.html as Firebase control panel
- preview.html to test the graphics locally

No videos are used.

Triggers:
- Stash or Pass graphic
- Spin 2 Choose 1 graphic

Included:
- Full 32-team scoreboard
- Sold/available controls
- Ticker/title/status controls
- Firebase connection status
- Uploaded transparent PNG graphics
- Swoosh WAV sound

OBS notes:
- Width: 1920
- Height: 1080
- Refresh browser when scene becomes active: ON
- For sound, enable/control browser source audio in OBS.


IMPORTANT FOR SOUND IN OBS:
1. Right-click Browser Source -> Properties
2. Enable:
   [x] Control audio via OBS
3. In OBS Audio Mixer:
   - Unmute the browser source
   - Raise volume to 0 dB
4. Refresh the browser source once after loading

If audio still does not play:
- Interact once with the browser source (click inside preview)
- Or reload the browser source after OBS starts
